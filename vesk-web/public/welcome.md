# Welcome to Vesk

A compiler-first reactive UI framework for the post-VDOM web.

## What's inside

- Server HTML and per-cell updates from one **.vsk** source
- Statement mode: bare JSX, `if`, `for`, `switch`, `try`
- Islands, SSR + hydration, and a tokenizer-based `<Md>` renderer

## Quick start

| Action | Command |
|:-------|:-------:|
| dev server | `npm run dev` |
| build | `npm run build` |
| typecheck | `npm run typecheck` |

- [x] compiler-first reactivity
- [x] statement mode
- [x] markdown from a file via `<Md content="/welcome.md" />`
