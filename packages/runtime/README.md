# @vesk/runtime

Vesk runtime — reactivity engine, block lifecycle, DOM operations, hydration, routing, and server APIs.

## Install

```sh
npm install @vesk/runtime
```

## Usage

```js
// Client
import { track, effect, derived } from '@vesk/runtime';

// Server
import { renderPage, parseCookies } from '@vesk/runtime/server';
```
